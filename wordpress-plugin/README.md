# SitePilot Connect (WordPress Plugin)

Planned independently installable WordPress plugin. It will expose scoped, authenticated WordPress operations through WordPress APIs, enforce capabilities and input/output security, and be structured for later extraction into its own open-source repository. Basic functionality must not require SSH or WP-CLI on the host.

Status: placeholder only. No plugin code or live site connection exists yet. See `../project-docs/SECURITY.md`.
